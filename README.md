# 미션 - 페어매칭관리 애플리케이션

# 구현 기능 목록
**1. [사전 작업] 파일에 저장된 크루들의 이름 목록을 List<String> 형태로 준비한다.**
   - 파일의 내용은 수정이 가능하기 때문에 매 프로그램 시작시 파일 입출력 로직이 필수로 돌아야 한다.

**2. [입력] 진행할 기능을 입력받는다.**
   - [예외 처리] 유효하지 않은 입력값일 경우 에러 메시지를 출력한다.

**3-1. [페어 매칭 - 입력] 매칭할 과정, 레벨, 미션을 입력받는다.**
   - [예외 처리] 유효하지 않은 형식의 입력일 경우 에러 메시지를 출력한다.
   - [예외 처리] 존재하지 않은 과정, 레벨, 미션일 경우 에러 메시지를 출력한다.

**3-2. [페어 매칭- 매칭] 크루들을 매칭한다.**
   - Randoms 라이브러리 사용
   - 마지막에 홀수로 떨어지는 경우 세 명을 매칭

**3-3. [페어 매칭 - 출력] 매칭 결과를 출력한다.**

**3-4. [페어 매칭 - 입력] 이전에 매칭된 페어가 존재하는 경우 재시도 여부를 입력받는다.**
   - [예외 처리] 3회 시도까지 매칭이 되지 않거나 매칭을 할 수 있는 경우의 수가 없으면 에러 메시지를 출력한다.
   - 동일 레벨 내에서 이전에 매칭된 페어가 존재하는지 판단 (다른 레벨은 상관 X)

**4-1. [페어 조회 - 입력] 조회할 과정, 레벨, 미션을 입력받는다.**
   - [예외 처리] 유효하지 않은 입력값일 경우 에러 메시지를 출력한다.

**4-2. [페어 조회 - 출력] 조회 결과를 출력한다.**
   - 조회 결과가 없을 경우 결과 없음 출력?

**5. [페어 초기화] 매칭된 페어 기록을 삭제한다.**

**6. [종료] 프로그램을 종료한다.**
